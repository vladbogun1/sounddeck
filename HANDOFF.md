# HANDOFF — SoundDeck

## Где остановились (2026-11-04)

**v1.4.0 выпущен** (2026-11-04, подписан `CN=SoundDeck (Self-Signed)`, запушено в main):

- **Самоустановка** (`app/Update/SelfInstall.cs`): запуск exe из любого места → копия в
  `%LocalAppData%\Programs\SoundDeck`, ярлык в «Пуске», запись в «Приложения» (`--uninstall`),
  перенос автозапуска, перезапуск оттуда. `--portable` / файл `portable` рядом — отключает.
- **Автообновление** (`app/Update/Updater.cs`, `UpdateCoordinator.cs`): `releases/latest` раз в 6 ч,
  ассет `SoundDeck.exe`, проверка размера + sha256 (`digest` из API) + тот же сертификат подписи;
  подмена exe (rename → .old), перезапуск при закрытом окне или сразу по кнопке.
  В Debug выключено, если не задан `SOUNDDECK_FAKE_VERSION`.
- **Доска**: сетка с переносом вместо горизонтального скролла, окно подгоняется под число устройств
  (`layout.js` → команда `fit`), pointer-drag с призраком/автоскроллом/доком (`drag.js`), FLIP-анимации,
  опрос состояния раз в 1.2 с, пока окно открыто.
- **Скрытие устройств** и карточка «Обновления» в настройках (`panels.js`).

Проверено: UI в браузере на моках (5 устройств, перенос в 2 колонки, док, настройки);
Debug-сборка в реальном окне; E2E в scratch: самоустановка из «Загрузок» → автообновление
1.0(фейк) → 1.3.0 с GitHub, чистый выход старого процесса.

## Что дальше

1. Следующий релиз: поднять версию в csproj, `dotnet publish` (команда в README), подписать
   signtool `/sha1 E8CF795F… /s My /fd SHA256 /tr http://timestamp.digicert.com`, `gh release create vX.Y.Z`
   с ассетами `SoundDeck.exe` + `SoundDeck-PublicCert.cer`. Имя ассета ровно `SoundDeck.exe`, тег `vX.Y.Z`.
2. У пользователя сейчас запущен `Downloads\SoundDeck (1).exe` (1.3.0) — после релиза один раз
   запустить новый exe, он сам установится. 1.3.0 обновиться сам не может (в нём нет апдейтера).
3. Хвосты из ревью (не сделано):
   - exe 160 МБ без сжатия — `EnableCompressionInSingleFile=true` уменьшит скачивание обновлений;
   - `AudioService` создаёт `MMDevice` на каждый вызов и не освобождает COM-объекты;
   - меню трея меняет язык только после перезапуска;
   - `installer/SoundDeck.iss` больше не нужен (версия в нём 1.0.0) — удалить или оставить как legacy;
   - README на de/es/ja/zh не обновлены (обновлены en и ru).
